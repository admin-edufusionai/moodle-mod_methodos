# Security Policy

## Supported Versions

The following versions of `mod_methodos` are currently receiving security updates:

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability in this plugin, please **do not** open a public GitHub issue.

Instead, please report it privately by emailing:

**security@edufusionai.co.za**

Please include:
- A description of the vulnerability.
- Steps to reproduce (if applicable).
- Any suggested remediation.

We aim to acknowledge all reports within **48 hours** and resolve confirmed issues within **14 days**.

Once a fix is available, we will:
1. Publish a patched release.
2. Credit the reporter in the release notes (unless you prefer anonymity).
3. Notify the Moodle security team if required.
